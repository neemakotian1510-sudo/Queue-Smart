# QueueSmart

### AI-Powered Smart Canteen Management System

QueueSmart is an intelligent canteen management system designed to reduce waiting time, manage food orders, and improve kitchen efficiency.

## Key Features

- Student online food ordering
- AI-assisted food preparation time estimation
- Smart pickup slot allocation
- First Come, First Served (FCFS) scheduling
- Automatic kitchen speaker announcements
- Live kitchen order dashboard
- Inventory and order management

## Technology Stack

- Python
- Streamlit
- SQLite
- Artificial Intelligence
- Text-to-Speech
